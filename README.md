## 🖼️ Features

- 🌈 **Split-Screen Gradient Layout**  
  - Smooth transition from `#667eea` to `#764ba2`
- 🔄 **Floating & Rising Background Animations**  
  - Shapes (circles, triangles, squares) drift subtly  
  - Rising bubble effect adds a calming atmosphere
- ✨ **Sequential Form Animations**  
  - Email, password, link, and button fade in smoothly
- 🔊 **Audio Feedback Integration**  
  - Audio plays at specific interactions:
    - Page load  
    - Button hover  
    - Form submission
- 📱 **Responsive Design**  
  - Looks great on all screen sizes
